# Huangbo Portfolio Lite

这是适合直接上传到 GitHub Pages 的轻量版部署包。

## 推荐使用这个版本的原因

- 只保留了页面实际引用的资源
- 首页个人照已经替换为你的新照片
- 图片做了网页尺寸优化，更适合 GitHub 网页上传

## 上传方式

不要上传压缩包。

请把这个文件夹里的内容上传到 GitHub 仓库根目录：

- `index.html`
- `.nojekyll`
- `README.md`
- `ziti-portfolio-assets/`

## GitHub Pages

上传完成后：

1. 打开仓库 `Settings`
2. 打开 `Pages`
3. `Source` 选择 `Deploy from a branch`
4. `Branch` 选择 `main`
5. `Folder` 选择 `/ (root)`

保存后等待 GitHub 生成公开链接。
